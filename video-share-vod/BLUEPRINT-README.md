# Video Share VOD listing preview

The Blueprint pins the verified official Video Share VOD3.1.11 archive and the existing immutable neutral listing images. It demonstrates eight fictional video-listing entries, not complete playable films or a production FFmpeg/conversion service. The provisioning recipe is GPL-2.0-or-later. Use a fresh disposable WordPress Playground sandbox; do not apply this fixture to an existing customer site.

The matching WordPress.org assets/blueprints recipe is retained. For cross-origin browser loading, use the raw GitHub copy of this JSON; SVN URLs may be readable to command-line clients while a browser fetch is blocked.
