# Video Share VOD Playground assets

Static, lightweight poster images for the Video Share VOD WordPress Playground blueprint.

The blueprint downloads these files into the disposable Playground upload directory. They are not bundled in the WordPress.org plugin ZIP, are not fetched by normal plugin installations, and are not videos or preview clips.

`images/originals/` contains the full poster shown on an individual demo-video page. `images/thumbnails/` contains proportionally resized 320-pixel-wide variants for the listing cards; no crop is used.

See `CREDITS.txt` for the license and `PROMPTS.md` for reproducible generation prompts.
