# MicroPayments creator catalog demo art

Six original, general-audience cover images generated by the built-in imagegen tool on 2026-11-04: coast, ceramics, botanical art, music, seasonal cooking and alpine landscape. These are fictional demo covers, not real paid media or creator identities. They support authentic screenshots and a reproducible WordPress Playground preview.

The generated images and their resized derivatives in this package are released by VideoWhisper under **CC0-1.0**. See https://creativecommons.org/publicdomain/zero/1.0/ . No credit link is required. There are no third-party photos, logos, brands, music, trackers or personal data. The application code retains its own license.

`images/covers/` contains 960x540 JPEGs and `images/thumbnails/` contains 480x270 JPEGs. Full generation prompts and hashes are in `asset-provenance.json`; PNG originals are retained in the project workspace, outside plugin runtime ZIPs. Derivatives use only resizing/JPEG compression. Covers are deliberately public marketing art, separate from protected content.

Pin consuming Blueprint URLs to the immutable commit after publication. Do not fetch these assets automatically during normal plugin activation. Demo provisioning is an explicit Playground action.
