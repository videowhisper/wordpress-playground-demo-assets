# MicroPayments creator catalog demo art

Six original, general-audience cover images generated by the built-in imagegen tool on 2026-11-04: coast, ceramics, botanical art, music, seasonal cooking and alpine landscape. These are fictional demo covers, not real paid media or creator identities. They support authentic screenshots and a reproducible WordPress Playground preview.

The generated images and their resized derivatives in this package are released by VideoWhisper under **CC0-1.0**. See https://creativecommons.org/publicdomain/zero/1.0/ . No credit link is required. There are no third-party photos, logos, brands, music, trackers or personal data. The application code retains its own license.

`images/covers/` contains 960x540 JPEGs and `images/thumbnails/` contains 480x270 JPEGs. Full generation prompts and hashes are in `asset-provenance.json`; PNG originals are retained in the project workspace, outside plugin runtime ZIPs. Derivatives use only resizing/JPEG compression. Covers are deliberately public marketing art, separate from protected content.

Pin consuming Blueprint URLs to the immutable commit after publication. Do not fetch these assets automatically during normal plugin activation. Demo provisioning is an explicit Playground action.

## Executable creator-site preview

[Open the WordPress Playground demo](https://playground.wordpress.net/?blueprint-url=https%3A%2F%2Fraw.githubusercontent.com%2Fvideowhisper%2Fwordpress-playground-demo-assets%2F0bb3e14934988ab89a6a50de04772823448e9df6%2Fpaid-membership%2Fblueprint.json). The matching `blueprint.json` pins the verified public releases MicroPayments 4.1.0, Video Share VOD 3.1.11, Picture Gallery 1.8.1 and FansPaysite 2.7.9. Versioned official ZIP URLs avoid moving-alias cache inconsistencies. It uses the immutable image/media commits recorded in the recipe, six fictional items and one draft, three fictional creators, and clearly fictional subscriptions and purchase records. No payment is collected. The two five-second clips are generated still-image motion with silent audio, not real films or recordings.

Discover, Creator feed, Included with subscriptions, My purchases, My studio and the Northlight Studio single-creator page showcase distinct listing tasks over the same content model. The Public preview workflow creates independent public 480-pixel promotional images; it does not protect a publicly reachable source file. No follow graph or recommendation service is implied.

Provision only in a disposable fresh Playground sandbox. The script requires the explicit local provisioning flag and refuses an ordinary existing customer site. The disposable default login belongs only to the sandbox; no customer credential is embedded. Do not use this recipe to overwrite a customer site. The provisioning recipe is GPL-2.0-or-later; the generated art and synthetic demonstration clips are CC0-1.0.
