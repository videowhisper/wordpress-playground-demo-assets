# Image-generation prompts

Use one prompt per asset. Preserve the common constraints for each replacement or new addition so the resulting thumbnails remain appropriate for a public WordPress.org preview.

## Common constraints

Original, unbranded, general-audience image; no sensitive content. Avoid text, lettering, logos, watermarks, signatures, brand marks, people, faces, nudity, copyrighted characters, UI elements and collage panels.
